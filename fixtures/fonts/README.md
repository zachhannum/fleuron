# The demo faces

`IMFellEnglishSC-Regular.ttf` is IM Fell English SC by Igino Marini,
a digitisation of the types John Fell gave Oxford in the seventeenth
century, under the SIL Open Font License 1.1 beside it as
`IMFellEnglishSC-OFL.txt`.

The demos set chapter heads in it and leave the prose to the bundled
Garamond, which is the pairing it was chosen for: the two are both
old-style, so a head and the page under it belong to one book. It is
a true small-caps face, and that is what a chapter head wants from a
subset with no `letter-spacing` in it.

One cut, and no italic: a head that would have been italic is set
upright instead.
