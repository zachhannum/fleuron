# The demo faces

`IMFellEnglishSC-Regular.ttf` is IM Fell English SC by Igino Marini, a
digitisation of the types John Fell gave Oxford in the seventeenth
century. Its SIL Open Font License 1.1 sits beside it as
`IMFellEnglishSC-OFL.txt`.

The demos set chapter heads in it and leave the prose to the bundled
Garamond. Both are old-style, and it is a true small-caps face, which
is what a chapter head needs in a subset with no `letter-spacing`.

One style, and no italic. A head that would have been italic is set
upright instead.
