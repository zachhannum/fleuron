Module fonts 

Source
Expand description

The font registry: font bytes in, font_ids out.

Both the shaper and every painter resolve glyphs through this one table, which is what makes preview equal export. The registry is the sole owner of font bytes; nothing else in the engine keeps a FontRef lifetime alive.
