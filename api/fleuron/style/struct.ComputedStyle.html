Expand description

One node’s resolved style: what every downstream pass reads.

Fields§

§font_id: u16

The face this style shapes with, resolved against the registry. Family, slope and weight chose it; layout only needs the answer.

§font_family: Vec<Family>

The families asked for, in order, kept for diagnostics and for the snapshot the style tree is reviewed through.

§font_size: f32

Font size in points.

§font_style: FontStyle

Upright or italic.

§font_weight: u16

Weight on the CSS 1–1000 scale.

§color: Color

What text and rules are painted in.

§line_height: f32

Line height as a unitless multiple of the font size.

§letter_spacing: f32

Extra advance after every glyph, in points, from letter-spacing.

§font_variant_caps: FontVariantCaps

Which capitals the run is drawn with.

§font_feature_settings: Vec<FeatureSetting>

The features the sheet asked the face for, from font-feature-settings. They are asked for after the ones the font-variant longhands name, so a tag in both is set here.

§font_variant_ligatures: FontVariantLigatures

Which ligatures the run is set with.

§font_variant_numeric: FontVariantNumeric

Which figures the run is set with.

§font_variant_alternates: FontVariantAlternates

Which alternate glyphs the run is set with.

§text_transform: TextTransform

What the run’s letters are transformed to before shaping.

§text_decoration_line: DecorationLine

Which rules are drawn across the run, from text-decoration-line.

§text_decoration_color: Option<Color>

What those rules are painted in, from text-decoration-color. None is the colour of the text.

§text_decoration_style: DecorationStyle

How each rule is drawn, from text-decoration-style.

§text_decoration_thickness: Option<f32>

How thick each rule is, in points, from text-decoration-thickness. None is the thickness the face declares.

§text_align: TextAlign

How lines fill the measure.

§text_justify: TextJustify

What justification opens up to fill it.

§hanging_punctuation: HangingPunctuation

Which marks may hang past the measure.

§text_indent: f32

First-line indent in points.

§hyphens: Hyphens

Whether words may break at syllable boundaries.

§orphans: u16

Lines that must be left at the bottom of a fragment.

§widows: u16

Lines that must be moved to the top of the next one.

§page: Option<String>

The named page this element’s pages take, from page.

§content: Content

What the element paints in place of children it has none of: the ornament a thematic break is set with.

§string_set: Vec<StringSet>

The named strings this element sets when the flow reaches it, from string-set. This is where a running head’s text comes from.

§counter_reset: Option<u32>

The folio the page this element opens takes, from counter-reset: page.

§note_reset: Option<u32>

The number the first note under this element takes, from counter-reset: note. On the footnote area it restarts the numbering on every page.

§initial_letter: u16

Lines an initial letter is sunk over, from initial-letter. Fewer than two is no drop cap.

§position: Position

Whether the element sits in the flow or against the page.

§inset: Edges<Inset>

What the insets say, for an element that is against the page.

§z_index: i32

Which layer the block paints in, from z-index. Higher paints later, and auto is layer 0.

§opacity: f32

How much of what the block paints shows, from opacity: 1 is all of it and 0 is none. The blocks inside it show that much of their own.

§mix_blend_mode: BlendMode

How what the element draws is mixed with what is under it, from mix-blend-mode.

§blend_around: BlendMode

The mode of the nearest element around this one that names one. An element is part of what the elements around it draw.

§wrap_flow: WrapFlow

Which side of this element the prose sets on, from wrap-flow.

§float: Float

Which side of its column an image in the flow moves to, from float.

§clear: Clear

Which floats the block starts below, from clear.

§shape_outside: ShapeOutside

The contour the prose sets around, from shape-outside.

§shape_margin: f32

How far the prose keeps off that contour, in points, from shape-margin.

§margin: Edges

Margins in points.

§padding: Edges

Padding in points, between the border and the content.

§border: Edges<Border>

The four border edges.

§border_radius: BorderRadius

How far each corner of the border box is rounded, from border-radius. The background and the border follow the corners.

§background: Background

What is painted behind the block: a tint, and an image over it.

§box_decoration_break: BoxDecorationBreak

What the decoration does where a page break splits the block.

§width: Width

The width the box is asked to take, from width. A table reads it off the cells of its first row to size its columns.

§height: Width

The height the content box is asked to take, from height.

§min_height: Width

The least height the content box takes, from min-height.

§max_width: Width

The most width an image takes, from max-width. Auto is none.

§max_height: Width

The most height an image takes, from max-height. Auto is none.

§border_collapse: BorderCollapse

Whether a table’s cells share their borders, from border-collapse.

§list_style_type: ListStyleType

The marker a list item is set with, from list-style-type.

§break_before: Break

Where a page break falls before this element.

§break_after: Break

Where one falls after it.

§break_inside: Break

Whether this element may be split across pages.

§column_span: ColumnSpan

Whether this element is set across every column of a divided page, from column-span.

§custom: BTreeMap<String, String>

The custom properties in force, by name, each with every var() in its value already replaced. A child inherits them.

Source

pub fn excludes(&self) -> bool

Whether prose is set around this element rather than over it: the sheet has taken it out of the flow, and it excludes a side.

This is the one place a contour is read, so it is also what decides whether one is traced. An element still in the flow takes a band of its own and nothing sets beside it, so a contour on it would answer a question nobody asks.

Source

pub fn content_box(&self, x: f32, measure: f32) -> (f32, f32)

This block’s content box inside measure: (leading edge, the measure its lines break to). Margin, border and padding come off both edges, and the leading edge moves in by what they take on the left.

Source

pub fn inline_box(&self) -> Option<InlineBox>

The box this style paints around the runs of an inline element, and None where it paints none and takes no width.

Padding counts even where nothing is painted over it: it is width, and the line breaks against it.

Source

pub fn blend(&self) -> BlendMode

The mode what this element draws is mixed in: its own, and otherwise the one the elements around it draw in.

Source

pub fn features(&self) -> Vec<FeatureSetting>

Every feature this style asks the face for, in the order the shaper reads them: what the font-variant longhands name, then what font-feature-settings spells out. A tag in both takes the value written last, which is the one the sheet spelled.

What is drawn across this style’s runs, the four longhands gathered into one value.
