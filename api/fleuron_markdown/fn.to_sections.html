Reads one source into sections, and everything the reading had to complain about.

source names the file for diagnostics and becomes every section’s source; it is what [fleuron::session::Session::replace_source] replaces by. Node ids are left unassigned: they are assigned in document order over a whole book, which is assemble’s job.
