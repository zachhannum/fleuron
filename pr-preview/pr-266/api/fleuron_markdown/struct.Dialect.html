Expand description

Which markdown a source is written in.

Dialect::fleuron is the default. The other three are named after whose markdown they read.

Fields§

§frontmatter: bool

A leading --- block is metadata rather than a scene break.

§attributes: bool

A line of nothing but {.class #id} names the block under it, and a heading or an image takes the same run written after it.

§tables: bool

Tables, written as GitHub writes them: a header row, a delimiter row, and one line per row.

§gfm: bool

GitHub’s other additions: strikethrough and task lists.

§wikilinks: bool

[[wikilinks]], as Obsidian writes them.

§smart_punctuation: bool

-- and " become dashes and curly quotes at parse rather than in the manuscript.

§breaks: bool

A line of nothing but \pagebreak or \columnbreak starts a new page or the next column.

§footnotes: bool

Footnotes, as GitHub writes them: [^1] in the prose, and [^1]: the note on a line of its own.
