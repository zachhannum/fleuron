Expand description

A block-level element: the unit of fragmentation input.

Variants§

§

Heading

# through ######; levels outside 1–6 are rejected at parse.

Fields

§id: NodeId

Engine-assigned identity, for diagnostics; never serialized.

§level: HeadingLevel

# count, 1-6.

§inlines: Vec<Inline>

The heading’s text, in reading order.

§attributes: Attributes

What a sheet names it by.

§position: Option<SourcePos>

Where the frontend read this from.

§span: Option<SourceSpan>

The bytes of that source it was read from.

CodeBlock

A code block: preformatted text, set as it was written.

It holds text rather than inlines, because a code block has no markup inside it. The text keeps the newlines and the spaces the author wrote, and those are what its lines break at.

Fields

§id: NodeId

Engine-assigned identity, for diagnostics; never serialized.

§info: Option<String>

The word after the opening fence, where one was written. It is carried for a painter that reads it, and the engine makes nothing of it.

§text: String

The block’s text, newlines and indentation intact.

§attributes: Attributes

What a sheet names it by.

§position: Option<SourcePos>

Where the frontend read this from.

§span: Option<SourceSpan>

The bytes of that source it was read from.

List

A list of items, numbered or not. An item holds blocks, as a blockquote does, so a list nests inside an item of another.

Fields

§id: NodeId

Engine-assigned identity, for diagnostics; never serialized.

§ordered: bool

Whether the items are numbered.

§start: u32

The number of the first item of a numbered list.

§tight: bool

Whether the source wrote the items without blank lines between them: a list of phrases rather than a list of paragraphs.

§items: Vec<ListItem>

The items, in reading order.

§attributes: Attributes

What a sheet names it by.

§position: Option<SourcePos>

Where the frontend read this from.

§span: Option<SourceSpan>

The bytes of that source it was read from.

§

Table

A grid of cells. A cell holds blocks, as a blockquote does.

Fields

§id: NodeId

Engine-assigned identity, for diagnostics; never serialized.

§head: Vec<Row>

The header rows, which name the columns, in reading order.

§body: Vec<Row>

The body rows, in reading order.

§attributes: Attributes

What a sheet names it by.

§position: Option<SourcePos>

Where the frontend read this from.

§span: Option<SourceSpan>

The bytes of that source it was read from.
