Module gate 

Source
Expand description

The gate: stage timings, a memory high-water mark, and the budgets CI checks them against.

Criterion answers “how fast, and did that change” for one stage in isolation. This answers the different question a release has to answer: does a whole book still fit inside the budget on the machine in front of us. It is one binary, no statistics beyond a best-of-N, and it reports the same numbers natively and under wasm.

Budgets are absolute ceilings, not comparisons against a stored baseline: run-to-run comparison needs a baseline that has been steady for a while, and a CI runner’s timings have not.
