pub fn measure(corpus: Corpus, registry: &FontRegistry, runs: usize) -> Report
Expand description

Measures one book, keeping the best time and the worst memory over runs.

Best-of, not mean: the question is whether the engine can hit the budget, and the slow runs are the machine’s noise, not the engine’s work. Memory goes the other way — a ceiling is only met if it is met every time.
