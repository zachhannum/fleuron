fleuron supports the CSS a book needs and reports the rest. Everything below is honoured by the pipeline. Anything outside it becomes a warning naming the line and column it was written at, and the run continues.

The stylesheet below is written in this vocabulary: mirrored margins, a folio, a running head from `string-set`, and a drop cap from `initial-letter`. Change a rule and the chapter is set again.

## Selectors

Type, universal, descendant, child, adjacent and general sibling. The structural pseudo-classes `:first-child`, `:nth-child()`, `:only-child`, `:empty` and `:root`. Also `:is()`, `:where()`, `:not()` and `:has()`.

Element names are the markdown vocabulary: `book`, `section`, `h1`–`h6`, `p`, `blockquote`, `hr`, `img`, `em`, `strong`, `code`, `a`. There are no classes, ids, attributes or namespaces, because the content tree has none, and no interaction pseudo-classes, because nothing here is interactive.

There is one pseudo-element, `::first-letter`, which is where a drop cap comes from. It cascades over the style of the element it belongs to, so a rule that names it starts from that element's own font and size.

Text runs are not elements. They take the style of the inline or block around them, and never count towards `:first-child`.

## Properties

Text, inherited:

| property | values |
|---|---|
| `color` | a colour name, `#rgb`, `#rrggbb`, `rgb()` |
| `font-family` | family names and `serif` / `sans-serif` / `monospace` |
| `font-size` | `<length>`, `<percentage>` of the parent |
| `font-style` | `normal`, `italic`, `oblique` |
| `font-weight` | `normal`, `bold`, `1`–`1000` |
| `line-height` | `normal`, `<number>`, `<length>`, `<percentage>` |
| `letter-spacing` | `normal`, `<length>` |
| `font-variant-caps` | `normal`, `small-caps` |
| `text-transform` | `none`, `uppercase`, `lowercase`, `capitalize` |
| `text-align` | `left`, `right`, `center`, `justify`, `start`, `end` |
| `text-justify` | `auto`, `inter-word`, `inter-character`, `distribute` |
| `text-indent` | `<length>` |
| `hyphens` | `none`, `manual`, `auto` |
| `hanging-punctuation` | `none`, or any of `first`, `force-end`, `allow-end`, `last` |
| `orphans`, `widows` | `<integer>` |
| `page` | a page name, or `auto` |

Block box, not inherited:

| property | values |
|---|---|
| `content` | `none` or a `<string>`, the ornament a thematic break is set in |
| `string-set` | `none`, or `<name> [content() \| <string>]+`, comma-separated |
| `counter-reset` | `none`, or `page <integer>` |
| `initial-letter` | `<integer>` lines to sink an initial letter over, on `::first-letter` |
| `margin` | one to four `<length>`s |
| `margin-top`, `margin-right`, `margin-bottom`, `margin-left` | `<length>` |
| `break-before`, `break-after`, `break-inside` | `auto`, `avoid`, `page`, `left`, `right`, `recto`, `verso` |

`recto` and `verso` are the book's names for `right` and `left`.

Lengths are `pt`, `px`, `pc`, `in`, `cm`, `mm`, `q`, `em`, `rem`, and everything computes to points. `em` in `font-size` is a multiple of the parent's size and elsewhere of the element's own. `rem` is always a multiple of the root's.

### Setting the measure

Lines break by total fit over the whole paragraph: every set of breaks is costed by how far each line is from the measure, cubed, and the cheapest set wins. A word pulled up to fill one line is not taken when it leaves a hole in the next.

`text-align: justify` opens the space between words to reach the measure exactly, on every line but the last. `text-justify: inter-character` lets the space between letters change as well. The default does not. Left, right and centred text break the same way and sit where the alignment puts them.

`hyphens: auto` adds syllable boundaries to the breaks a line may take, each charged for the hyphen it leaves and for coming after another one. No more than two lines in a row end hyphenated.

### Display typography

`letter-spacing` is advance added between the glyphs of a run, and the total-fit pass measures it like any other width. Nothing is added after a line's last glyph, so a tracked title centres on its own letters rather than on the space after them.

`font-variant-caps: small-caps` takes the face's `smcp` feature. A face without one draws its lowercase as capitals at four-fifths of the size, and a diagnostic names it, so an author can pick a face that has them.

`text-transform` changes the characters that are shaped. What a painter reads back is the text the author wrote: the run has the source and the shaper's mapping into the transformed form, so a PDF's text extraction, a search over it and copy and paste all return the manuscript. `capitalize` raises the letter a word opens with, where a word continues through letters, digits and the apostrophe inside one.

### Colour

`color` is the ink a run is set in. It inherits, so a colour on `section` reaches the prose under it and a rule on `h1` beats what the heading inherited.

The values are a CSS colour name, `#rgb`, `#rrggbb`, and `rgb()` over numbers or percentages. There is no alpha channel.

The preview and the PDF fill from the same colour.

### Hanging punctuation

`hanging-punctuation` lets a mark sit outside the measure so the edge of the text block reads straight. A full stop or a comma at the end of a line leaves a hole in the margin, and hanging it closes the hole.

`first` hangs an opening quotation mark or bracket back into the margin the line starts at. `force-end` hangs a closing mark past the measure on every line; `allow-end` hangs one only where that is what makes the line fit. `last` hangs the mark a paragraph ends on.

How far a mark hangs depends on the mark: most of a full stop or a comma, less of a colon, and none of a letter.

### Breaking

`break-inside: avoid` moves a block whole rather than split it. `orphans` and `widows` bound where a paragraph may be cut: fewer than `orphans + widows` lines and it moves whole too. Where no allowed break remains, the page ends anyway.

### Running heads

`string-set` is where a running head's text comes from. The element sets the named string when the flow reaches it, and a margin box reads it back with `string()`. `content()` is the element's own text, which only headings and paragraphs have any of.

### Folios

`counter-reset: page <integer>` is where the folio restarts. The page the element opens takes that number, and the pages after it count on from there. Blank leaves count.

Recto and verso do not follow the folio. Which side of the spread a page falls on is where it sits in the sheet, not what is printed on it, so front matter restarting the body at 1 leaves the sides alone.

### Drop caps

An initial letter is sized from the sink rather than from `font-size`. Its cap height spans `initial-letter` lines, so its baseline lands on the last of them and its top on the first line's cap height. The lines beside it break to the measure it leaves.

## `@page`

```css
@page <name>? [:first | :blank | :left | :right]* {
  size: <length>{1,2} | a3 | a4 | a5 | b4 | b5 | letter | legal | ledger [portrait | landscape]?;
  margin: ...;
  @<margin-box> {
    content: none | counter(page[, <counter-style>]) | string(<name>) | <string>;
    /* text properties */
  }
}
```

`<counter-style>` is `decimal`, `lower-roman`, `upper-roman`, `lower-alpha` or `upper-alpha`. A number the style cannot express falls back to decimal.

`string(<name>)` reads a running string as it stood when the page opened, not as the first element on the page set it, so a chapter opening halfway down a page does not retitle the page it opened on. A string nothing has set yet paints nothing.

A page group begins wherever a section opens a page, so `:first` selects a chapter's opening page rather than only the book's. `:blank` selects a page inserted to square the sheet. `:left` and `:right` are verso and recto.

Page selectors cascade like any other rule: origin first, then specificity, then source order. The name outweighs `:first` and `:blank`, which outweigh `:left` and `:right`.

All sixteen margin boxes parse. Six paint: `@top-left`, `@top-center`, `@top-right` and their `@bottom-` counterparts. A `-center` box is centred on the trim rather than on the content box, because a folio belongs on the page's axis and mirrored margins put the content box off it. `-left` and `-right` align to the content box's edges.

A page the flow put nothing on paints no margin boxes at all, so a page whose only content would be a running head does not get one. `@page :blank` still gives that leaf its trim and margins.

## `@font-face`

```css
@font-face {
  font-family: "Author Serif";
  src: url("faces/author.ttf") format("truetype"), local("Author Serif");
  font-style: normal;
  font-weight: 400;
}
```

The string in `url()` is handed to the loader unchanged, and does not have to be a real URL. A face that resolves registers under the family the sheet declared, not the one inside the file. A face that resolves nowhere warns, and text falls back to the next family in the list.

`font-family` is tried in order and the first registered family answers. Within it, slope decides before weight. No slope or weight is synthesised. See [fonts](library/fonts.md) for the full matching rules and how variable files register.

## Not in the subset

Backgrounds, borders, padding, floats, tables, grid, flexbox, transforms, media queries, custom properties, counters other than `page`, `counter-increment`, `font-variant` beyond `font-variant-caps: small-caps`, and generated content beyond page margin boxes, `string-set`, and `content` on an empty element.

Each is reported per declaration, at the line and column it was written at. These are properties the engine does not support yet, not properties it rules out.
